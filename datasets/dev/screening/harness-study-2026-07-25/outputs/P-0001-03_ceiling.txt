## Endpoint Style

Use kebab-case for all new Platform API resource names in path segments. Write resource words in lowercase and join them with hyphens so new endpoints match the existing Platform API surface consistently.

Sample paths:
- `/v1/build-artifacts`
- `/v1/service-accounts`
- `/v1/tenant-usage-reports`
