## 3. Benchmark construction

### 3.1 Event streams and probes
- Simulated org event streams (`docs/specs/event-stream.md`); witnessed
  per-principal delivery; twin (counterfactual) streams.
- Probe archetypes and the capability ladder: A4, A7 (rung 1), A1 (rung 2),
  A2 (rung 3) (`docs/specs/probe-spec.md` v0.4.3, `docs/vision.md` §3).
- Pair credit: an instance passes only if base AND twin sides pass
  (`docs/specs/probe-spec.md` §4) — guards against answering from priors.

### 3.2 Screening and gates
- G0–G5 gate pipeline (`docs/dataset-plan.md`); what each gate screens.
- Blinded judging protocol: opaque-id export → fresh judges → import; judge
  model ≠ worker model ≠ criterion-author family (`AGENTS.md` hard rules).
- Judge validation: 20-decoy false-accept audit (2/41 measured, 0/39
  adjudicated — `datasets/dev/screening/judge-decoys/audit.json`); 150-pair
  human agreement (G4) — number TBD when the packet returns; criteria < 0.7
  dropped, never rewritten.
- Frozen dataset: seeds 1–3, 371 valid instances (A1 50, A2 43, A4 106,
  A7 172); per-seed 125/131/115; seed 3 instance gate carried as an explicit
  FAIL. Seeds 4–5 unscreened holdouts. Freeze prespecified 2026-08-15,
  corroborated by git history (`docs/decision-log.md`).

### 3.3 Harness sensitivity
- Identical weights behind a different harness agree only 65% on twin-ceiling
  outcomes (harness study, `docs/decision-log.md` /
  `datasets/dev/screening/harness-study-2026-07-25/`) → motivates the single
  pinned worker (gpt-5.4, effort medium, codex-cli 0.144.5) for every
  protocol path.

## 4. Systems and experimental setup

- Inclusion rule: top-4 GitHub-stars market systems at 2026-08-15 (Mem0,
  Cognee, Graphiti/Zep, Supermemory); Letta rank 5 excluded by the rule; full
  candidate table + every exclusion (`docs/vendor-survey.md`). No

- Baselines: no-memory (floor), full-transcript (ceiling anchor), grep-agent,

- Scoring: pair credit; normalized (sut−floor)/(ceiling−floor) clipped [0,1];
  cluster-robust SEs; cross-seed combination; ≥2/3-seed rank-direction rule
  (`scripts/score_sut.py`, `scripts/figures.py`).

  Mem0; H3 portability (deferred, not v1).
- Cost columns are mandatory results, not an appendix: worker seconds, wall

## 7. Limitations and disclosures (inventory — each becomes a sentence or two)

1. Single author-rater for G4 human agreement (has seen seed content);
   downgrade from the original two-rater design, disclosed with the measured
   agreement number.
2. Rank-direction robustness downgraded from 4/5 seeds to ≥2/3 (v1 runs 3 of
   the 5 planned seeds; seeds 4–5 held out unscreened).
3. Seed-3 instance gate carried as FAIL; instances retained and marked.
4. Worker billing moved from a chatgpt-plan account to an OpenAI API key
   behind the same pinned binary (model/version identical).
5. Market systems' internal LLM/embedder set to Gemini where configurable
   (one billing surface); deviation from each vendor's default named in
   `docs/vendor-configs.md`. Supermemory runs fully vendor-managed (hosted;
   not configurable) — the one system on vendor defaults end to end.
6. Shared-store configurations do not enforce per-principal visibility; v1
   scores no leakage. Per-principal ACL evaluation is deferred.
7. Silo ablation runs on Mem0 only — full-transcript silo yields byte-identical
   context, making the ablation vacuous there; corrected before any run,
   dated in `docs/decision-log.md`.
8. Graphiti runs on the embedded Kuzu driver (in 0.29.3, deprecated upstream);
   no docker on the run machine ⇒ no Neo4j.
9. Simulated orgs, not real logs; 3 seeds; single worker model — external
   validity limits stated plainly.
10. Vendor right-of-reply: raw results + harness to each vendor 7 days before
    submission; replies summarized in an appendix.
